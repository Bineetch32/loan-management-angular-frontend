# Loan Management Angular Frontend

Standalone Angular 17 frontend for the new Spring Boot Loan Management backend.

## Run
npm install
ng serve

Open http://localhost:4200

Backend: http://localhost:8081

This repository is separate from the old loan-Management-FullStack project.

## Features
Login UI, Dashboard, Loan Application, Loan List, Approve/Reject/Sanction, Documents, and EMI Calculator.

Demo login is frontend-only because the current backend does not expose authentication endpoints.
